# BallotBox

BallotBox is a secure e-voting system for small orgs (clubs, coops, unions) solving the core tension: ballots must be secret (untraceable to voters) yet verifiable (tally is auditable). Built on the 50.005 CoreStack/tetriSH libraries, it delivers a CLI-based voter client and admin control tool (ballotctl) over a custom C backend (ballotd), communicating via SSH/shell sessions. Key guarantees: encrypted traffic, no double-votes, no ballot-to-voter linkage in logs, and concurrency-safe tallying.

---

- Admin: a person who runs and manages e-voting.
- Voter: a person who casts a vote.
- Observer: a person who is eligible to observe the voting results, under usual circumstances, a voter and an admin are also an observer.
- System: a backend service that runs and manages ballotbox programmes.
- Client: a frontend service or a GUI that voter or admin interact.

## Use Cases

### UC-1: Instantiate BallotBox

| Field            | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Description      | Admin creates and starts a new election instance.                                                                                                                                                                                                                                                                                                                                                                                               |
| Actors           | Admin                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Triggers         | Admin runs ballotctl create.                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Preconditions    | Valid admin cert; ballotd reachable.                                                                                                                                                                                                                                                                                                                                                                                                            |
| Postconditions   | A new election exists with its config and authoritative store, ready to open.                                                                                                                                                                                                                                                                                                                                                                   |
| Error States     | Invalid admin cert → rejected and logged.bad config (no options / invalid times) → rejected.                                                                                                                                                                                                                                                                                                                                                    |
| Flow             | Admin runs ballotctl create with title, options, eligible-voter cert list, and open/close times. Client opens a secure session and presents the admin cert. System verifies the admin cert. System validates the configuration. System initialises the authoritative store for the election in _Draft_. Admin runs ballotctl open. System transitions the election to _Open_ and begins accepting voters. System confirms the instance is live. |
| Alternative Flow | 4a. If config is invalid, System returns the specific error and stays in _Draft_ for the Admin to fix and retry.                                                                                                                                                                                                                                                                                                                                |

### UC-2: Join BallotBox

| Field            | Detail                                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Description      | An eligible voter joins an open election instance.                                                                                                                                                                                                                                                                                                                                                                 |
| Actors           | Voter                                                                                                                                                                                                                                                                                                                                                                                                              |
| Triggers         | Voter runs the join command with the election ID.                                                                                                                                                                                                                                                                                                                                                                  |
| Preconditions    | Voter holds a valid client cert; election is _Open_.                                                                                                                                                                                                                                                                                                                                                               |
| Postconditions   | Voter is admitted to an authenticated session and can cast a ballot.                                                                                                                                                                                                                                                                                                                                               |
| Error States     | Forged/expired cert → rejected; cert not on eligible list → refused.Election not open → refused.                                                                                                                                                                                                                                                                                                                   |
| Flow             | Voter runs join \<election-id\> in the CLI client. Client presents the voter's X.509 cert and opens a secure session (libtetrissh handshake). System verifies the cert and checks it against the eligible-voter list. System confirms the election is _Open_. System admits the voter and returns the ballot definition (motion/candidate options). Client displays the options and confirms the voter has joined. |
| Alternative Flow | 3a. If the voter has already cast a ballot, System still admits them and routes to UC-4 (update).                                                                                                                                                                                                                                                                                                                  |

### UC-3: Cast a Vote

| Field            | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Description      | Voter submits a secret ballot and receives a verifiable receipt (hash).                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Actors           | Voter                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Triggers         | Voter runs the vote command after joining.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Preconditions    | Voter has joined an _Open_ election (UC-2); no final ballot cast yet.                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Postconditions   | One authoritative ballot recorded; receipt hash issued; no log links the ballot to the voter.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Error States     | Replayed/duplicate → refused.Election closed mid-submit → rejected.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Flow             | Voter runs the vote command. Client displays the ballot options. Voter enters their selection. Client asks the voter to confirm. Voter confirms. Client encrypts the ballot (RSA-OAEP) with a fresh anti-replay nonce and submits it over the session. System verifies the nonce/sequence and re-checks eligibility. System records the ballot in the authoritative store and durably commits it. System returns a signed receipt containing the ballot's verification hash. Client displays the receipt hash and a success message. |
| Alternative Flow | 7a. If the voter already has a final ballot, route to UC-4 (update).                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

### UC-4: Update a Vote

| Field            | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Description      | Voter re-casts to override a prior selection while voting is still open.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Actors           | Voter                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Triggers         | Voter runs vote again before the close time.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Preconditions    | Election _Open_; voter has ≥1 prior ballot.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Postconditions   | Tally counts only the latest ballot version; a new receipt hash is issued; secrecy preserved.                                                                                                                                                                                                                                                                                                                                                                                            |
| Error States     | Election closed mid-submit → rejected.                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Flow             | Voter re-runs the vote command. System confirms the cert and that the election is still _Open_. Client displays the options and notes a prior ballot exists. Voter enters a new selection and confirms. Client encrypts and submits the new ballot. System stores it under a higher version for the voter's anonymous token; only the latest version counts. System marks the previous receipt superseded and returns a fresh receipt hash. Client displays the updated success message. |
| Alternative Flow | 1a. If voter haven’t voted yet → UC-3: cast a vote5a. Concurrent updates → System serialises them and keeps the highest version (see Risk R1).                                                                                                                                                                                                                                                                                                                                           |

| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| Actors           | Observer                                                                                                                                                                                                                                                      |
| Triggers         | Observer runs the results command after the election is published.                                                                                                                                                                                            |
| Preconditions    | Election _Closed_ and results published by the Admin.                                                                                                                                                                                                         |

| Flow             | Observer runs the results command. System returns the final tally and the public result view: the aggregate counts plus the list of all ballot hashes. Client displays the tally. Client displays the hash list so a voter can later locate their own (UC-6). |

### UC-6: Check Your Vote

| Field            | Detail                                                                                                                                                                                                                           |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Description      | A voter confirms their own ballot was counted, using their receipt hash.                                                                                                                                                         |
| Actors           | Voter                                                                                                                                                                                                                            |
| Triggers         | Voter runs the check command with their receipt hash.                                                                                                                                                                            |
| Preconditions    | Voter holds a receipt hash from UC-3/UC-4; results published.                                                                                                                                                                    |
| Postconditions   | Voter confirms inclusion of their ballot without revealing their choice to anyone else.                                                                                                                                          |
| Error States     | Hash not found → flagged as a dropped ballot.Superseded hash → points to the current version.                                                                                                                                    |
| Flow             | Voter runs check \<receipt-hash\>. Client looks the hash up against the published result view. System confirms the hash is present and unmodified in the tally. Client reports that the voter's ballot was included and counted. |
| Alternative Flow | 3a. If the hash is missing, Client reports a verification failure for the voter to raise with the Admin.                                                                                                                         |
